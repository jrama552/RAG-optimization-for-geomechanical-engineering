# RAG-optimization-for-geomechanical-engineering
This repository contains a sanitized/redacted version of the pipeline developed under the guidance and instruction of Principal Investigator Professor Boris Jeremic, during the UC Davis YSP.

# Project Overview
This project explored the use of retrieval-augmented generation (RAG) to improve the transformation of NL descriptions into DSL for the Real-ESSI Simulator, developed by Professor Jeremic.

The goal of this project was to develop a pipeline that could retrieve the most relevant and technical information (from supplied sources) to inform better responses, and ultimately make extremely domain-specific and technical systems like the REAL-ESSI Simulator more accessible to users with less knowledge.

The main focus of this improvement in accuracy pertains to syntactical accuracy, a key struggle in many domain-specific language (DSL)-generating LLMs.

# Contents
This repository contains a scrubbed subset of the implemented code including the RAG and document retrieval pipeline, text chunking/embedding methods, NL to DSL generation process, and a variety of evaluation methods.

More in-depth information about the goals, process, context, and results can be found in the attached 'Optimization RAG for Real-ESSI DSL.pdf' file.


This repository is meant demonstrate the pipeline design, implementation and general methodology of the research completed while also preserving confidentiality of Dr. Jeremic's work.
