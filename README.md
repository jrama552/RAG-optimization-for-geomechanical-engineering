# RAG-optimization-for-geomechanical-engineering
This repository contains a sanitized/redacted version of the pipeline developed under the guidance and instruction of principal investigator Professor Boris Jeremic, during the UC Davis YSP.
This pipeline was created and ran through Google Colab. 
More in-depth information about the goals, process, context, and results can be found in the attached 'Optimization RAG for Real-ESSI DSL.pdf' file.

Most (or all) proprietary DSL files, simulator input and outputs, and FEI/ESSI has been redacted, removed, or replaced.
